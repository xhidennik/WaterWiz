# WaterWiz

Демонстрационная система учёта и управления для тепличного и фермерского хозяйства. Проект создан как «цифровое» решение для реальных производственных процессов партнёра — ООО «Джей Джи Си Эвергрин» (JGC Evergreen), Хабаровский край.

## Возможности

- **Главная** — лендинг с описанием системы и переходом в дашборд.
- **О нас** — информация о системе и о компании JGC Evergreen, фотогалерея (карусель).
- **Дашборд** — графики урожая, расхода воды, распределения площадей по культурам; блоки по фермам/участкам.
- **Склад** — вкладки «Инвентарный склад» и «Продукция фермы»; данные в localStorage, вывод таблиц динамический.
- **Полив (Задачи и календарь)** — календарь на любой месяц (январь 2016 — февраль 2026), задачи на день с ответственным, статусом, местом; генерация и хранение в localStorage.
- **Админка** — график загрузки RAM/CPU в реальном времени, лог событий, прогресс диска, расширенная системная информация (всё на условных данных).
- **Личный кабинет** — открывается по клику на аватар в шапке: контакты, активность, безопасность.

Адаптивная вёрстка: на экранах уже 500px меню превращается в бургер, таблицы прокручиваются по горизонтали.

## Как запустить

Статические HTML/CSS/JS — сервер не обязателен. Достаточно открыть в браузере:

- `index.html` — главная (или любой другой `.html` из корня).

Для разработки удобно поднять локальный сервер, чтобы не упираться в CORS при загрузке файлов, например:

```bash
# Python 3
python -m http.server 8000

# или npx (Node.js)
npx serve .
```

После этого открыть в браузере: `http://localhost:8000` (или указанный порт).

## Стек

- HTML5, CSS3 (модульные стили: colors, global, buttons, blocks, text, mobile).
- Ванильный JavaScript (без фреймворков).
- Chart.js — графики на дашборде и в админке.
- Tiny Slider — карусель на странице «О нас» (подключение из `assets/tiny-slider/`).
- Font Awesome — иконки.
- localStorage — склад и задачи полива.
